# Fearprime PTSD assessment schedule v2.0

## Princip

Clinical outcomes and mechanistic learning outcomes are sampled on different time scales. No single session score is treated as the treatment outcome.

## Baseline

Collect a stable pre-intervention window sufficient to characterize ordinary variability in:

- PTSD symptom burden (PCL-5; CAPS-5 through clinician when indicated)
- function
- intrusion burden
- avoidance
- sleep/nightmares
- hyperarousal/hypervigilance
- dissociation/interoceptive distress where relevant
- major confounders

Baseline length is protocol-dependent rather than hard-coded. Chronic interventions should use a longer baseline than acute learning tests.

## Learning session

Before the event:

1. Identify memory target, stimulus and context.
2. Record prediction and confidence.
3. Lock prediction before the outcome is observable.
4. Capture pre-state.

After the event:

1. Capture actual outcome.
2. Capture post-state.
3. Score learning-quality fields.
4. Record protocol deviations and adverse events.

## Delayed follow-up

### 24h

Use for early retention and to detect major sleep/stress confounding. Do not use 24h alone to declare a stable consolidation phenotype.

### 7d

Primary delayed memory checkpoint for the Fearprime consolidation model. Where possible, keep same-context retrieval, stimulus generalisation and context transfer as separate observations.

### 30d

Use for clinical/function trajectory and persistence of changes. It is not a substitute for the 7d mechanistic endpoint.

## Return-of-fear

Represent separately:

- spontaneous recovery: time-dependent return
- renewal: context-dependent return
- reinstatement: return after subsequent aversive/stressor event

Fearprime should not deliberately create harmful stressors to manufacture a reinstatement test.

## Chronic-state interventions

For interventions whose expected effect is weeks/months (for example a chronic psychiatric-state intervention), collect repeated clinical state rather than attributing an acute session change to the intervention.

## Sleep as a lagged variable

Record the prior-night sleep state so the analysis can ask whether sleep predicts next-day learning and delayed retention.

## Clinical anchor

The clinical endpoint hierarchy is:

1. function and clinically meaningful symptom change
2. standardized PTSD assessment
3. mechanistic learning outcomes
4. physiological/wearable signals

Wearable or smartphone signals are supporting measurements, not standalone PTSD diagnoses.
