# PDF blood-test preview

The import screen must present a reviewable extraction before persistence.

## Preview fields

- Source file name
- SHA-256 fingerprint
- Detected laboratory
- Detected collection date
- Extraction method: native text / OCR / manual
- Detected markers
- Canonical marker
- Value
- Unit
- Reference interval
- Confidence
- Warning badges
- Source page when available

## Actions

- Confirm all
- Confirm selected
- Edit value/unit/date
- Exclude result
- Cancel import

No parsed result is considered part of the longitudinal record until the user confirms it.
